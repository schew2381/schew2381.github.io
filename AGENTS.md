# schew2381.github.io

Personal Jekyll blog on the Chirpy theme.

Posts live in `_posts/`, and `_posts/AGENTS.md` is the style guide every
post has to follow.

`tools/prose-report.py` is an advisory checker for drafts, described at
the end of that guide. Run it locally after writing, treat what it flags
as candidates to go read rather than errors to clear, and don't mistake
a clean run for good writing.

## Git workflow

Commit directly to `main` and push. That is the entire workflow.

- No pull requests.
- No worktrees.
- No feature branches.

`main` is the only branch that matters. Don't leave others behind,
locally or on the remote.

Push without stopping to ask for confirmation.
